# *Important*
This project is discontinued as the school ended and the Robotics club could not tune the drone. It could fly for a second or two, but it consistently failed to fly stably. There could be many reasons behind this, including frame vibration, insufficient power, bad propellers, incorrect PID formula, low power motors and more. It was an amazing experience and we wish this project is continued again in the future.

# ESP32 Drone
## Project Description
Charles P. Allen Robotics club's project in 2025-2026 school year is to build a mini drone. Its functions include PID balancing with MPU6050 and basic controls. Future implementations could be FPV camera and automatic landing to a RC boat.

# Components Used
## Controller
- XIAO ESP32C3 with External Antenna
- Perfboard
- 2X Joysticks

## Drone
- XIAO ESP32S3 Sense with External Antenna
- 4 x DRV8833
- MPU6050
- 4 x 716 Corless Motors
- 3D Printed Drone Frame
